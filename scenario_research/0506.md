## 1. 현재 방향 재정의

현재 `scenario_research`는 **헷지 추천 엔진이 아니라 장세 진단 엔진**으로 둔다.

역할 분리는 다음과 같이 가져간다.

```text
scenario_research
= 오늘의 장세 진단
= 어떤 시나리오가 강한지, 왜 강한지, confidence/coverage가 충분한지 설명

HedgeMate
= scenario_research의 진단 결과를 입력으로 받음
= 자산별 시나리오 민감도 매핑과 결합
= 포트폴리오 개선/헷지 후보 추천
```

따라서 `scenario_research`가 직접 “SHY를 사라”, “GLD를 사라” 같은 추천을 하면 안 된다.  
그 판단은 HedgeMate가 수행한다.

---

## 2. 현재 문제 인식

### 2.1 현재 시나리오 진단의 기준

현재 Phase 4 시나리오 리서치는 **미국/글로벌 장세 중심**이다.

주요 proxy:

- 미국 위험자산: `SPY`, `QQQ`, `SOXX`
- 미국 금리/채권: `TLT`, `TIP`
- 신용/위험선호: `HYG`
- 달러/환율: `UUP`, `KRW=X`
- 원자재/에너지/금: `DBC`, `USO`, `GLD`
- 변동성: `^VIX`
- 한국/아시아 보조: `EWY`, `FXI`

따라서 현재 `Soft Landing / Goldilocks`는 정확히는:

> 미국/글로벌 위험선호가 좋고, 금리/달러/변동성 스트레스가 크지 않은 장세

이지,

> 한국장 전체가 확실히 좋은 장세

라는 의미는 아니다.

### 2.2 한국장 중심 사용 시 주의점

한국장에서는 미국장과 다른 장세가 나타날 수 있다.

예:

- 미국장은 risk-on인데 한국장은 원화 약세/중국 둔화 때문에 부진
- 미국장은 약한데 한국 반도체는 독자적으로 강세
- 미국 AI/반도체는 강하지만 삼성전자/하이닉스는 메모리 가격·환율·외국인 수급에 따라 다르게 반응

따라서 시나리오 진단 결과는 앞으로 lens를 분리해야 한다.

```text
US / Global Regime
Korea Market Regime
Korea Semiconductor Regime
FX / KRW Regime
China / Asia Regime
```

## 3. 최종 목표 구조

최종 구조는 다음과 같다.

```text
[Scenario Research]
오늘 장세 벡터 생성

예:
- Soft Landing: 83
- Stagflation: 49
- Long-rate Shock: 40
- USD/KRW Weakness: 24
- China Shock: 30
- confidence / coverage 포함

        ↓

[HedgeMate]
1. 포트폴리오의 scenario exposure 계산
2. 후보 자산의 scenario exposure 계산
3. 후보 추가 후 exposure 변화 계산
4. CVaR / MDD / volatility 개선 확인
5. 같은 factor 과다노출 페널티
6. 최종 포트폴리오 개선 추천
```

핵심은:

> 시나리오 리서치는 “오늘 어떤 장인가”를 말하고,  
> HedgeMate는 “이 장세에서 내 포트폴리오를 어떻게 개선할지”를 판단한다.

## 4. Scenario Research에서 해야 할 일

### 4.1 추천 문구 제거 / 진단 문구 강화

`scenario_research`는 추천이 아니라 진단만 한다.

좋은 출력 예:

```text
US/Global 기준 Soft Landing 강세
- 위험자산 상승
- 달러/원화 부담 제한적
- 장기금리 충격 낮음
- confidence 높음

주의:
- 이 결과는 한국장 직접 판단이 아니라 미국/글로벌 lens 중심임
- 한국장은 USD/KRW, EWY, FXI, 반도체 proxy를 별도 확인해야 함
```

나쁜 출력 예:

```text
오늘은 Soft Landing이므로 SHY/GLD를 추천
```

이런 추천은 HedgeMate로 넘긴다.

### 4.2 Dashboard에 lens 명시

현재 dashboard에 아래 항목을 추가하는 것이 좋다.

```text
Primary Lens: US / Global
Korea Overlay: 부분 반영
FX Overlay: USD/KRW proxy 반영
China Overlay: FXI/EWY proxy 반영
```

그리고 각 시나리오 설명에도 다음 문구를 추가한다.

```text
이 장세는 미국/글로벌 proxy 중심으로 판단한 결과입니다.
한국장 적용 시 환율, 중국, 반도체 민감도를 별도 확인해야 합니다.
```

## 5. HedgeMate에서 해야 할 일

### 5.1 asset × scenario sensitivity matrix 만들기

HedgeMate에는 다음 형태의 민감도 매트릭스가 필요하다.

```text
ticker, scenario_code, lens, sensitivity, direction, confidence, evidence
NVDA, soft_landing_goldilocks, US_GLOBAL, +0.85, benefits, high, ...
NVDA, higher_for_longer_long_rate_shock, US_GLOBAL, -0.60, vulnerable, medium, ...
005930.KS, china_trade_fragmentation_shock, KR_ASIA, -0.70, vulnerable, medium, ...
000660.KS, korea_semiconductor_upcycle, KR_SEMI, +0.90, benefits, high, ...
SHY, acute_global_stress_liquidity_crunch, US_GLOBAL, +0.40, defensive, medium, ...
GLD, usd_strength_krw_weakness, FX_KRW, +0.35, defensive, medium, ...
```

이 매트릭스가 있어야 HedgeMate가 다음을 판단할 수 있다.

```text
현재 장세에 포트폴리오가 취약한가?
후보 자산을 추가하면 취약도가 줄어드는가?
아니면 같은 장세 민감도를 더 키우는가?
```

### 5.2 추천 점수에 current scenario 반영

현재 HedgeMate는 주로 아래를 본다.

- CVaR 개선
- MDD 개선
- stress 개선
- S&P500 beta/corr 감소
- 유동성

앞으로는 여기에 다음 항목을 추가한다.

```text
current_scenario_vulnerability_reduction
factor_concentration_penalty
scenario_alignment_score
```

권장 점수 구조:

```text
final_score =
  0.30 * CVaR 개선
+ 0.20 * MDD 개선
+ 0.20 * 현재 장세 취약도 감소
+ 0.15 * factor 중복 감소
+ 0.10 * 유동성
+ 0.05 * 설명 가능성
```

### 5.3 같은 factor 추가 금지 / 페널티

중요한 룰:

```text
이미 포트폴리오가 AI/반도체/growth factor에 많이 노출되어 있으면
NVDA, AVGO, QQQ, SOXX long을 헷지 후보로 강하게 추천하면 안 된다.
```

이들은 진단용으로는 중요하지만, 포트폴리오 개선 추천에서는 같은 방향 베팅을 키울 수 있다.

단, 무조건 제외는 아니다.

```text
좋은 장세에 민감한 자산 = 수익 기회일 수 있음
나쁜 장세에 취약한 자산 = 추천 페널티
이미 과다노출된 factor = 추가 추천 페널티
```

### 6.2 포트폴리오 개선/헷지 후보

실제로 포트폴리오 개선 후보로 평가할 자산이다.

```text
SHY
IEF
GLD
IAU
TIP
XLP
XLU
XLV
DBC
USO
```

### 6.3 조건부/주의 자산

아래 자산은 무조건 헷지 후보로 쓰면 안 된다.

```text
NVDA
QQQ
SOXX
EWY
FXI
BTC-USD
ETH-USD
```

이유:

- `NVDA`, `QQQ`, `SOXX`: 반도체/growth factor를 더 키울 수 있음
- `EWY`, `FXI`: 한국/중국 위험을 줄이기보다 같은 지역 노출을 키울 수 있음
- `BTC`, `ETH`: 위기 때 방어자산보다 risk asset처럼 움직일 가능성이 큼
